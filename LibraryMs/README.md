# LibraryMS v0.1

## Giới thiệu

LibraryMS là ứng dụng quản lý thư viện đơn giản được xây dựng bằng Flask.

## Chức năng

- Hiển thị danh sách sách.
- Hiển thị số lượng đầu sách.
- Hiển thị số sách sẵn sàng cho mượn.
- Lọc sách theo thể loại.
- Xem chi tiết sách.
- API trả về danh sách sách dạng JSON.
- API xem chi tiết sách theo ID.
- Xử lý lỗi 404 tùy biến.

## Công nghệ

- Python
- Flask
- HTML
- Jinja2
